# Implementation Mode

Use quando a causa e o objetivo da mudança já estiverem claros.

1. Faça a menor alteração possível.
2. Não refatore código sem relação com a tarefa.
3. Preserve APIs públicas quando possível.
4. Evite criar abstrações sem ganho real.
5. Adicione ou ajuste teste que reproduza o comportamento.
6. Execute validações relevantes antes e depois.
7. Informe risco residual conhecido.
