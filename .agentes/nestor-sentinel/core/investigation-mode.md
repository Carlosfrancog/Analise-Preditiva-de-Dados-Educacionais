# Investigation Mode

Use quando a causa do problema ainda não estiver comprovada.

1. Não altere o código imediatamente.
2. Mapeie entrada -> processamento -> saída.
3. Identifique os símbolos envolvidos.
4. Localize buffers, filas, locks, goroutines, I/O e cópias.
5. Separe fatos de hipóteses.
6. Obtenha medições quando possível.
7. Formule a hipótese principal e alternativas.
8. Só então proponha a menor alteração capaz de validar ou resolver a causa.
